# Evidence

Each researched subject has an evidence directory:

- `INDEX.md` gives every significant finding an ID, such as `RPF9-F07`, with its supporting evidence type, build, RVA, confidence and limits. Specifications cite these IDs.
- `research-history.md` records interpretations that were corrected, and why.

The index states what supports each finding and where to look in the build. It does not reproduce disassembly, decompiler output or archive data.
