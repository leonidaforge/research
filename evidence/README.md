# Evidence

Each researched subject has an evidence directory:

- `INDEX.md` gives every significant finding an ID, such as `RPF9-F07`, with its supporting evidence method or canonical evidence type, build, RVA, confidence and limits. Specifications cite these IDs.
- `research-history.md` records interpretations that were corrected, and why.

The index states what supports each finding and where to look in the build. When a finding depends on restricted private evidence, the index records an opaque evidence ID and the dependency instead of a key-material locator. It does not reproduce disassembly, decompiler output, archive data or secret state.
