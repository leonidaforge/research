# Builds

Observations tied to one executable: addresses, vtables, object layouts and function roles. Each build has a directory under `builds/<game>/<platform>-<first 8 hex digits of SHA-256>/`.

Addresses are given as RVAs. For a build with image base `B`, `VA = B + RVA`.
