# Formats

On-disk structures and parsing rules, grouped by category. [STRUCTURE.md](../STRUCTURE.md#formats) explains the categories and where a format belongs.

| Category                           | Formats |
| ---------------------------------- | ------- |
| [containers](containers/README.md) | RDS5, RPF9 |
| [metadata](metadata/README.md)     | RBF0    |
| [resources](resources/README.md)   | RAGE resource serialization |
| [unknown](unknown/README.md)       | EDUP, KB2j, KB2n, PSIN, PTFX, SGD5, type 14, GFX*, ADAT |

[CATALOG.md](CATALOG.md) indexes every observed family with its confidence, population, established structures and remaining unknowns. [CAPABILITY.md](CAPABILITY.md) records what research and the application can each do per format. A family appears here once its own document exists; the catalog also lists unidentified payload structures and shared serialization mechanisms that are not formats.
