| Format                 | Identification    | Status                                                                 |
| ---------------------- | ----------------- | ---------------------------------------------------------------------- |
| [RBF0](rbf0/README.md) | ASCII `RBF0` at 0 | Header, object body, field dictionary and observed value forms known |
